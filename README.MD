# To-Do List App

A simple and interactive To-Do List application built with HTML, CSS, and JavaScript. The app allows users to add tasks, mark tasks as completed, and delete tasks. It uses browser Local Storage to save tasks so they remain available after refreshing the page.

## Screanshot
![alt text](<images/To-do App.png>)


## Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Prevent users from adding empty tasks.
- Save tasks using Local Storage.
- Automatically restore saved tasks when the page loads.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/quophi14/javascript-todo-list.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
